# 恶毒的月夜棋盘 · 3D

基于 [恶毒的月夜棋盘](https://redial233.github.io/lemalin-chess/)（2D）的立体网页版：Three.js 棋盘 + Stockfish 16 本地对战。

## 本地打开

Stockfish Worker 需要 HTTP，不能用 `file://`。

```bash
cd /workspace/lemalin-chess-3d
python3 -m http.server 8765
```

浏览器打开：http://127.0.0.1:8765/

## 操作

- **选子 / 走子**：左键（或触控轻点）点棋子，再点合法格
- **镜头**：右键拖动旋转 · 滚轮缩放 · 中键平移
- **触控**：单指拖转 · 双指缩放 · 轻点选子
- 升变出现遮罩选后 / 车 / 象 / 马

## 视觉（v2）

- 华丽分层基座棋子：银白+淡紫（白）/ 深蓝黑+青荧（黑），金属清漆材质
- 精致棋盘边框：斜切底座、银紫镶线、四角宝石
- 特效：选中光环+上升粒子、合法格脉动、走子拖尾、吃子碎光爆发、将军警示脉冲、环境星尘与月光柱
- **吃子交战特写**：镜头推近 + 两子对撞/击飞（哈利波特魔法石棋局风），可在设置关闭

## 功能

- 立体棋盘与几何体棋子（王车象马后兵可辨）
- 合法格高亮、走子平滑动画、吃子落下消失
- 本地 Stockfish 对战（时制 / 执子 / 棋力 0–20 / Elo）
- 提示箭头、评估条、开局库、逐步评价、悔棋 / 认输 / 翻转视角
- 复盘分析、PGN 导入导出
- 恶毒秘书气泡（像素 / 矢量画风）

## 与 2D 版差异

| | 2D | 3D |
|---|---|---|
| 棋盘 | DOM 格子 + SVG 棋子 | Three.js 立体几何体 |
| 镜头 | 无 | 可旋转缩放 |
| 走子 | 瞬移 | 平滑移动 + 吃子动画 |
| 依赖 | 无 CDN | three.js（jsDelivr CDN） |
| 原项目 | `lemalin-chess` | 本目录独立，不覆盖 2D |

## 文件

- `index.html` / `style.css` / `app.js` — 界面与对战逻辑

## 对面就座的恶毒（加密 MMD 模型 · 仅私人使用）

- 左侧勾选「显示恶毒」，输入模型密码后点「载入」。浏览器用 WebCrypto 在本地解密 `models/lemalin.enc`，模型只以内存 blob URL 交给 three.js MMDLoader，不落盘。
- 恶毒坐在引擎执子那一方的棋盘后面，面向指挥官；有呼吸、眨眼、思考歪头，吃子、被吃、将军、终局时有表情反应。吃子交战特写期间会暂时隐身，免得挡镜头。
- 密码错误、没有模型包或浏览器不支持解密时，会提示并回退到 Q 版秘书，不影响下棋。WebCrypto 需要 https 或 localhost。
- 仓库里**只有加密包**，没有明文 pmx 或贴图（`.gitignore` 已屏蔽）。重新生成：

```bash
CHESS_MODEL_PASSWORD='…' MODEL_SRC=/path/to/碧蓝航线_恶毒 python3 tools/build_model.py
```

加密参数：PBKDF2-HMAC-SHA256，250000 次迭代，16 字节随机盐；AES-256-GCM。贴图降到 1024 像素，只打包主模型用到的 3 张。

### 恶毒亲手走子 · 右侧 3D 头像

- 打开「显示恶毒」后，引擎的每一步都由她亲手完成：伸手 → 手指合拢 → 抬起 → 移到目标格 → 放下 → 松手 → 收手。手臂用两骨解析 IK（肩、肘、腕），配合身体前倾和侧转。
- 吃子时：开着「吃子交战特写」就走原来的特写；关着则先把被吃的子拿到棋盘旁消散，再走子。
- 远处格子手够不到时，她会尽量前倾伸手，剩下的距离由“魔力”把棋子托过去，带星屑拖尾。
- 普通走子约 1.8 秒，吃子约 3.4 秒。收手不阻塞输入；动画期间的时间算在她自己的钟上。关闭「显示恶毒」时照旧直接移动。
- 右侧头像：用第二个 renderer 渲染同一个场景和同一个模型，相机跟随她的头骨，动作和表情完全同步，不会再解密一次。未载入或密码错误时显示原来的像素头像。
